# Tag manager

Rename a hashtag everywhere (or merge it into an existing hashtag). Delete removes the hashtag from photo sets without deleting photos or captions. The public pages update automatically.

Select a tag.

Tips

Hashtag pages are generated automatically for all tags that have photos. For example, #filmphotography opens its own URL. If two hashtags should be combined, rename one to the other. Album names can be entirely different from tags.

Before deleting a hashtag, make sure you do not want that category anymore. Deletion keeps the original photos and Instagram captions.

Local editor only. When done, close with Control+C and publish the updated data/, photos/ and page files via Git.
